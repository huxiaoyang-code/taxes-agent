# 调用记录、失败和恢复

直接工具自动留存开始、结束、实际输入输出、版本、耗时、来源与结果引用。日常报告展示金额、凭证/计算、规则；深入排错时再查看调用和输入原件。完整记录不会因只显示摘要而丢弃。

调用、记录、业务和写账状态分别核查：工具返回成功不等于业务完整，展示失败不等于业务未执行，只有开始记录的调用可能中断。未取得明确结果时保留未知，先查询原业务或账簿，再决定是否续做。

读核对可以按相同原件重算；正式写入的来源、业务键和批次身份必须稳定。已有成功或未知写入不可通过换名字重复执行。导入沿原`book_import_batch`查询，凭证核实际ID和状态，其余业务按真实工具的恢复入口处理。

对记录引用使用实际返回的ID或本机位置，不推测目录或将任意文件当回执。记录摘要与原件哈希是定位/变化证据，不替代语义与真实性核查。缺件、冲突和算法问题分别报告，保留失败和原始输入；修复后新增结果，不覆写历史。

恢复数据库或更换实例须遵守已有备份恢复控制，不把复制文件说成已恢复。资料、账库和调用记录分别备份并保留关联；客户真实数据与凭据不得提交Git或PR。
