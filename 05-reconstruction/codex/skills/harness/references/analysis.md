# 差异分析与经营说明

以明确的企业、账套、期间、币种、比较口径和目标开始。主Agent可以查询账簿、读取获准资料、选择计算工具并组织分析，不先登记分析任务或执行图。

核对金额差异后，再按真实明细解释价格、数量、结构、期间、一次性事项或输入/规则/工具问题。与原件或原生结果不同的模型推导单列，不能把语言模型算式改写为工具已确认。没有预算、同行可比资料或可靠原因时保留缺项，不生成方便解释。

经营规划与税后现金按[顾问指引](../../taxes-company-advisor/references/planning-cash.md)核实历史基线、方案前提及支付日期。税费规则和计算用`finance_rules`及`finance_tax_calculate`；未支持的规划分支给有根据的分析结构和待核事项，不声称引擎返回完整方案。

报告先给账本及方案金额、差额、现金日期，再给凭证/计算和规则依据。调用与原件引用用于深度调查，不以元数据状态替代业务结论。业务事实更新后重算受影响部分，保留此前预测及失效原因。
