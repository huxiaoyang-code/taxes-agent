# 读取其他业务入账规则

日常销售、采购、费用、资金往来等业务的通用规则。科目以账套实际科目表为准
（`account_list` 查询）；若需要的明细科目不存在，先 `account_create`，否则 `voucher_check` 报错。

## 销售与收款

| 业务 | 借方 | 贷方 |
|---|---|---|
| 赊销开票 | 应收账款 1122（价税合计） | 主营业务收入 5001（不含税）+ 应交税费 2221（销项税） |
| 现销收款 | 银行存款 1002 | 主营业务收入 5001 + 应交税费 2221 |
| 收回货款 | 银行存款 1002 | 应收账款 1122 |
| 预收货款 | 银行存款 1002 | 预收账款 2203 |
| 结转销售成本 | 主营业务成本 5401 | 库存商品 1405 |

## 通用要求

- `entries` 每行 `{ code, debit, credit, summary? }`，至少两行、借贷平衡、金额非负、单行不双向。
- `accountSetId` 与 `period` 必须显式；不要假设"当前账套"会保留。
- 流程：`voucher_check` → `voucher_create`（草稿）→ 在当前授权范围内 `voucher_post`；只有授权缺失时才确认。
- 涉及税额的分录，税额以用户提供的已核实数据为准，不自行估算。
- 摘要写明业务对象与单据号，便于 `ledger_query` / `voucher.detail` 复核。
