# 其他日常业务

先核实际企业、准则、科目、期间及原件。以下是业务检查指导，不是固定分录模板；原生支持范围由实际工具决定。

| 业务 | 需要核对 |
|---|---|
| 销售与收款 | 履约/索款、发票、价税、往来和成本；回旧应收不重复收入 |
| 采购与付款 | 收货/入库、价税、抵扣、应付及核销；预付不直接作成本 |
| 费用 | 实际受益对象、期间、资格和付款，不随意全记管理费 |
| 出资与借款 | 原合同/决议、稳定身份及支付，资本/本金与收入区分 |
| 租赁、工程及制造 | 按原合同、履约、材料人工和已支持分支核，不以行业名替代业务事实 |

按需读取`finance_record_contract`，原始业务用`finance_workpaper`；明确分录用`voucher_check`。科目使用`account_list`当前结果，不能把小企业示例科目套到其他准则。创建明细科目或正式写账须在实际授权及支持范围内执行。

不支持事项可给有来源的判断、候选草稿及待核条件，不能用错误record类型、技术占位或SQL改账让程序通过。完整调用和原件自动记录；输出先金额、凭证/计算与规则，再深入工具和输入。
