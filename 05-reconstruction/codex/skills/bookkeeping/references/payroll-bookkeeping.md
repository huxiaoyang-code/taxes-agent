# 工资与薪酬核算

逐人逐月核工资归属、实际发薪、合法扣除、官方社保公积金核定、已扣及支付；不让客户先给最终税额，也不把公司汇总自动分配个人。

## 计算与账务

用`finance_record_contract`查看工资、核定和支付记录合同；以`finance_tax_calculate`核已支持个税分支，资格及来源读`finance_rules`。官方应缴与任意参数试算不同，未接通分支保留待核。

| 环节 | 账务与证据 |
|---|---|
| 工资计提 | 按实际受益对象归集费用/成本与薪酬负债，核属期 |
| 单位承担贡献 | 官方核定、受益对象、期间和已登记负债 |
| 发放工资 | 应付、个人承担、代扣与实发勾稽，核实际银行记录 |
| 税款与贡献缴纳 | 负债与银行支付核销，不用应纳数字冒充已缴 |

科目使用账套实际准则和明细。用`finance_workpaper`生成业务草稿或对明确分录`voucher_check`，再按实际授权使用凭证工具。核应付、税费、其他往来及现金，与工资和核定明细勾稽。

输出累计/本期金额、计提与支付凭证、计算和规则依据，逐人资料与完整调用记录留本机授权范围。没有正式个税申报或缴款服务，工具计算不证明已申报。
