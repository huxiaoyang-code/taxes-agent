# 报销与费用核对

核原始票据、实际经营用途、费用归属、经办与报销关系、审批及支付证据。审批通过不自动证明税前扣除或进项资格；个人消费和企业经营费用分开。

## 选择处理

- 用`finance_record_contract`取得expense字段；行政、销售、生产、服务、运输、工程、出租等用途按实际受益对象选。
- 当前费用、预付、跨期受益与资产分别判断，不能为方便全部记管理费用。
- 用`finance_workpaper`形成草稿；扣除和抵扣交`finance_tax_calculate`及`finance_rules`核定。价款、税额、含税合计及本期抵扣分别列示。
- 个人垫付、尚未报销、公司已付款均需真实结算支持；没有收付资料不能默认unpaid或paid。

已有明确分录使用`voucher_check`核金额与科目，实际授权内调用凭证工具。报销清单、工具结果和付款不得混为同一状态。保留重复票据、证据冲突与需调查项，不按差额编单。

交付按账本金额、凭证/计算、规则依据展示；完整调用和输入原件自动留存，日常报告不展开个人明细或原文。
