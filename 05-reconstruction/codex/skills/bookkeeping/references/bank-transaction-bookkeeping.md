# 银行收付与往来核对

核实际银行账户、流水编号、日期、金额、交易性质及关联原业务。来源、企业和期间隔离；金额相同不能证明同一事项，收款不必然本期收入、付款不必然本期费用。

## 核销与账务

原始业务用`finance_record_contract`查询collection/supplier_payment，按真实relatedFactId、bankAccountId、bankReference和金额编制输入。汇总收付足以支持参考余额，不足以伪造逐笔分配。工具不支持一条流水拆分时保留具体缺口，不通过重复流水身份强行写入。

已有账簿用`ledger_query`和`finance_query`核期初、本期和期末；实际可用银行工具按本机已选草稿合同使用，不把任意文件路径当已接入。银行结单与账簿差异分未达、需调整、口径和待调查。

| 事项 | 判断与支持 |
|---|---|
| 收旧应收/付旧应付 | 原业务与期初、核销剩余余额；避免再次计收入成本 |
| 预收/预付 | 合同权利义务、交付及结算；与收入费用区分 |
| 手续费/利息 | 原单、归属期间、借贷和实际科目 |
| 股东及借款 | 合同、实际性质及支付，不能一概作收入、费用或分红 |

正式凭证先校验，按实际授权和业务控制写入。未知结果先查原身份，不能换流水号重试。报告先余额差额和凭证，再给依据，调用和原件通过深入索引核查。
