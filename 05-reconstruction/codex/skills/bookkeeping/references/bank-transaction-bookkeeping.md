# 读取银行流水入账规则

> 本机分支**没有银行流水数据源**：不导入银行对账单、不查询未入账流水、不做自动匹配与去重。
> `fund.unbooked.list` / `fund.unbooked.summary` / `enterprise_account.bank` 均不可用。
> 本规则只说明：**当用户提供了已核实的银行流水数据**时，如何登记成凭证。

## 输入要求

每笔流水至少需要：交易日期、金额、收付方向（收/付）、对方户名、摘要或用途、对应期间。
方向不清、金额与业务不匹配、缺少期间时先询问，不得凭摘要猜测对方科目。

## 分录规则（科目以 `account_list` 为准）

**收款**

| 情形 | 借方 | 贷方 |
|---|---|---|
| 收回货款 | 银行存款 1002 | 应收账款 1122 |
| 预收货款 | 银行存款 1002 | 预收账款 2203 |
| 直接销售收款 | 银行存款 1002 | 主营业务收入 5001 + 应交税费 2221 |
| 收到借款 | 银行存款 1002 | 短期借款 2001 / 长期借款 2501 |
| 收到投资款 | 银行存款 1002 | 实收资本 3001 |

**付款**

| 情形 | 借方 | 贷方 |
|---|---|---|
| 支付货款 | 应付账款 2202 | 银行存款 1002 |
| 支付费用 | 管理费用 5602 / 销售费用 5601 等 | 银行存款 1002 |
| 银行手续费 | 财务费用 5603 | 银行存款 1002 |
| 支付借款本金 | 短期借款 2001 / 长期借款 2501 | 银行存款 1002 |
| 支付利息 | 财务费用 5603 | 银行存款 1002 |
| 内部转账（银行→现金） | 库存现金 1001 | 银行存款 1002 |

涉及增值税的按发票规则价税分离，以用户提供的税额为准，不自行估算。

## 调用与核对

1. `voucher_check` → `voucher_create`（草稿）→ 在当前授权范围内 `voucher_post`；只有授权缺失时才确认。
2. 建议一笔流水对应一张凭证或按同一业务成组，摘要写明交易日期与银行流水号，便于人工对账。
3. 用 `ledger_query({ accountSetId, code: "1002", period })` 核对银行科目余额与流水累计发生额是否一致。

## 明确不做

- 不导入/解析银行对账单文件，不做收付款自动匹配、去重、银行余额调节。
- 不连接网银或银行接口；不要用"未入账流水"等工具名暗示已接入。
