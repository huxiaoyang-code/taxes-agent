# 读取发票入账规则

> 本机分支**没有发票数据源**：不采集、不查验、不读取发票明细、不做发票台账。
> `invoice_collect` / `invoice_file` / `invoice.detail` / `invoice.unbooked.*` 均不可用。
> Agent 从原始资料提取并核验字段，再按实际支持条件登记凭证；不要求客户提供结构化模板、预制分录或税务处理结论。

## 输入要求

先调查原始资料并保留定位、原文及核对结果；关键事实缺失或冲突时具体补件，不猜测：

- 发票类型：增值税专用发票 / 普通发票 / 电子发票 / 红字发票；销方还是购方。
- 票面不含税金额、税额、价税合计及已载明的税率；金额不一致时查原件和更正依据，不选择方便通过的值，不要求客户先算税。
- 纳税人资格及适用期间的登记依据、票据真实性质、交易双方、实际用途、履约/验收、受益期间与付款事实。Agent 根据核验事实和可核验规则提出并验证处理，记录适用条件与判断理由；客户不负责提供“可抵扣/不可抵扣”结论。
- 开票日期、对方名称、商品或服务摘要。

## 分录规则

科目以账套实际科目表为准（`account_list` 查询）。本机默认 COA 只提供 `2221 应交税费` 一个
税金科目，没有 `222101` 等明细；若确需明细，先用 `account_create` 建立子科目，否则
`voucher_check` 会报"科目不存在"。所有金额为不含税/税额/价税合计的确定值，不自行估算税额。

以下仅为满足各自适用条件后的分录示例，不是自动抵扣资格判定或新增税额算法。优先读取现有业务规则；例如 `small-admin-service/1` 在 small-2011、小规模身份、当月完成并全部受益的未付行政服务等条件成立时，业务模块使用价税合计形成费用/应付草稿。执行状态与会计复核状态分别记录，`accountingApproval=pending` 不得冒充已复核。

原生 offline 路径仍有实际边界：tax readiness 要求会计角色及登记依据，invoice adapter 只接受真实发票及数字发票号。不能伪造会计角色、将商业收据冒充发票或改写票号来通过；条件不满足时如实保留该入口阻塞。在已有任务授权内，可按 `harness/references/accounting.md` 的 treatment 路径保存来源/政策、判断、内部草稿、代码与验证，再调用现有 voucher 业务入口执行有依据的处理并待会计复核；必要原始事实仍不足则保持阻塞。

**采购（已核验事实与适用规则支持进项抵扣）**

| 科目 | 借方 | 贷方 |
|---|---|---|
| 库存商品 1405 / 原材料 1403 / 相关费用 5602 等 | 不含税金额 | |
| 应交税费 2221（进项税额） | 税额 | |
| 应付账款 2202 / 银行存款 1002 | | 价税合计 |

**采购（已核验事实与适用规则支持进项不抵扣）**：价税合计全额计入成本或费用，不拆分进项税。

**销售开具发票**

| 科目 | 借方 | 贷方 |
|---|---|---|
| 应收账款 1122 / 银行存款 1002 | 价税合计 | |
| 主营业务收入 5001 | | 不含税金额 |
| 应交税费 2221（销项税额） | | 税额 |

**红字发票**：按用户提供的红字发票数据冲减对应收入/进项，方向与原分录相反；金额以红字发票为准。
本地不开具红字发票，也不申请红字信息表。

## 调用与核对

1. `voucher_check({ accountSetId, entries })` 确认借贷平衡、科目存在。
2. `voucher_create({ accountSetId, period, voucher_date, summary, entries })` 生成**草稿**。
3. 在当前授权范围内 `voucher_post` 过账；只有授权缺失时才向用户确认。
4. 摘要在凭证里写明发票号码与对方名称，便于人工核对（本地没有发票—凭证关联表）。

返回的凭证对象包含 `id`、`status`、`total_debit`、`total_credit`、`entries`；汇报时原样给出关键字段。

## 明确不做

- 不采集/下载发票原件，不查验真伪，不维护进销项台账，不判断发票是否重复入账。
- 本地这些工具不提供通用图片/PDF识别；宿主 Agent 可调查、编写解析代码并保存验证与未识别内容。
- 不用票种、摘要或单一身份标签替代完整适用条件；不编造资格或会计确认，不把待复核处理宣传为已批准公共规则。
- 不计算应纳税额、不做申报。金额取可追溯原件或已有业务模块结果，保留核验依据。
