# 发票与采购销售核算

取得真实合同、发票及其关联、交付验收、索款和收付款。发票文件存在不是在线查验或税务资格确认；会计收入、开票、收款和纳税义务分别判断。

## 直接处理

按业务用`finance_record_contract`读取purchase/sale/sale_return/expense的完整字段，以`finance_workpaper`生成原生草稿、库存和税费结果。科目以实际账套及准则为准，不把单一科目示例通用于全部主体。

| 业务 | 主要核对 |
|---|---|
| 采购 | 入库数量、原价、价税、用途、认证期和结算；可抵扣与本期确认分开 |
| 销售 | 实际履约及索款、原始含税口径、发票及未开票；成本法与数量批次 |
| 退货 | 原销售/原票与红字支持、数量、实际入库、收入税额冲回和原成本恢复 |
| 费用 | 实际受益用途和期间、价税关系、资格及收付；销售配送用sales，运输履约成本为transport |

税费与抵扣调用`finance_tax_calculate`及`finance_rules`。不得因为专票而一概抵扣，也不能因尚未确认就认定永久不得抵扣。

核明细、分录、成本库存和应收应付，缺件或不支持分别列示。原件只读，完整调用和整理输入自动保存；报告先金额、凭证/计算、规则，深入再查工具与原件。
