# 固定资产与无形资产

核购置合同、发票、可用状态、实际用途、付款、已有总账、资产卡片和历史折旧。准则、寿命、残值及方法须有依据，不能把工具缺省值当企业已选政策。

## 购置与卡片

原件业务按`finance_record_contract`和`finance_workpaper`处理；实际科目和抵扣资格分别核验。`asset_create`登记卡片与购入凭证是不同操作，卡片存在不证明已增加总账原价；资产尚未入账的实际状态须保留。

| 核对项 | 内容 |
|---|---|
| 原价 | 购入价款、不可抵扣税和应计入成本项目，不能重复资本化 |
| 卡片 | 实际类别、取得/启用期间、寿命方法、残值和期初累计 |
| 账簿 | 资产原价、累计折旧/摊销、减值及支付或往来 |
| 处置 | 真实处置、原账面金额、税费和支付，不删卡片掩盖历史 |

## 折旧摊销与期末

按真实可用方法及卡片资料使用`depreciation_run`等现有工具，核当前及历史计提、剩余额和总账。工具只支持的固定方法不得描述为支持任意方法。税务折旧与会计差异通过实际规则和工具核对。

卡片或来源变动可能影响已结转/封账期间，遵守实际错误和更正顺序，不绕过期间校验。报告先账本及卡片金额，再给凭证/计算和规则，调用及原件在深入索引。
