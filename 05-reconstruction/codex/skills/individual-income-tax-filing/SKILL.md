# 个人所得税核对

核实居民身份、任职、逐人逐月工资、支付日期、合法扣除、减免、历史预扣及更正。公司汇总不自动分配到个人，不猜扣除资格或日期。

## 工作流程

1. 取得本次获准资料并限定企业、人员和期间；个人明细保持本机授权边界。
2. 用`finance_rules`读取实际扣缴分支及来源，通过`finance_record_contract`查工资和核定记录，以`finance_tax_calculate`计算。
3. 分开工资归属、发薪、会计计提、代扣及实缴。社保公积金参数试算不冒充官方核定，缺历史资料列为待核。
4. 先给累计与本期金额、凭证/计算、规则依据；调用及输入原件按需展开。未知不补0，人审与申报状态不代填。

按需读[工具](references/native-tool-map.md)和[补件更正](references/workflow-state.md)。税率表和公式由工具维护。没有税局登录、正式个税申报或缴款功能，历史名称不代表已接通。
