# 年度结算与税会核对

本文件由Anthropic官方月结和结账方法改编，来源、修改及Apache许可见[SOURCES.md](SOURCES.md)和[LICENSE](LICENSE)。现改为直接业务工具；日历和依赖仅是Agent可调整的业务指导，不建立运行时DAG。

## 工作流程

### 1. 确定年度范围

核实企业、账套、实际准则、经营起月、年度、币种和真实账簿。陌生企业先调查并按[旧账导入](../legacy-book-import/SKILL.md)核对历史，不因有账库就视为完整。缺资料仅影响相关事项，已有支持的独立核对可继续。

### 2. 核账与原件

用`finance_query`、`ledger_query`等核全年期初、本期发生和期末，关联库存、资产、往来、工资与税务承接。原始资料按月份和实际经营期间核验；月汇总、十二个成功记录或账表平衡都不能证明全年完整。

### 3. 年度计算与调整

以`finance_annual_workpaper`重放同企业全年原始资料；具体支持期间与条件读取当前合同。规则来源使用`finance_rules`。全年计算不等于年度关账或汇算完成。调整草稿附原业务、准则/税务理由及对本期和次年的影响；重大前期差错或工具未覆盖保持待核。

### 4. 复核和承接

按实际业务先后核对折旧摊销、结转、资产负债、损益和税费；这不是固定编排。正式写账、结账和更正使用现有授权及业务工具，实际人审不代签。重算后保留原版本和差异，不自动继承旧接受；检查次年余额与台账是否一致。

### 5. 年度核对包

按[报告顺序](../harness/references/reporting.md)先给全年账本与报表金额，再给调整凭证/计算及规则依据。调用和原始输入在深入排错时索引，完整记录始终保存。列明缺月份、冲突、工具不支持、实际复核和未决影响；不宣称完成真实申报、缴款或税局年度流程。
