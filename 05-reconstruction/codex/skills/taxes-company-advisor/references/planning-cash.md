# 税费规划与税后现金

先问清老板的经营目标、决策期限和约束，并从历史核实回款、毛利、库存/成本、费用、税款与现金占用。既有数据足够时直接整理基准；不要反过来让老板先给最终税额。方案只考虑真实、可执行的交易与合规安排，不按目标税负调账、虚构成本或把税负“压到行业值”。

## 政策与税费口径

每个方案先确认组织形式、税务身份、经营地点、交易性质、税点、所属期及优惠资格。使用国家税务总局、福建税务、财政部等官方来源，实际打开正文及附件，记录文号、条款/表式、地区、适用对象、生效/失效期和查询日期。区分发布日与适用期，历史业务用当时有效规定；候选新政策不能自动激活现有核算规则。

检索起点（以下列名政策正文于 2026-10-28 访问核查，使用时仍需验证修订和适用性）：

- [国家税务总局政策法规库](https://fgk.chinatax.gov.cn/) 与 [福建税务](https://fujian.chinatax.gov.cn/)：作为查询入口，查业务时点及地区政策、办税期限和口径。福建站本次访问超时，未据此核实任何地区政策或期限；运行时需实际取得对应正式文件。
- [2025 年第 17 号企业所得税预缴表公告](https://fgk.chinatax.gov.cn/zcfgk/c100012/c5241820/content.html)：核查适用主体、预缴表及附表；不代表完整年度汇算。
- [企业所得税法实施条例](https://fgk.chinatax.gov.cn/zcfgk/c100010/c5194417/content.html)：核查税基、扣除、调整等适用规则及修订状态。
- [2023 年修订公司法](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5233383/content.html) 与 [财资〔2025〕101 号](https://zcgls.mof.gov.cn/zhengcefabu/202506/t20250625_3966569.htm)：核查公司利润分配、弥补亏损等财务处理及生效期；不直接套用于个体户、合伙企业。

查不到当前有效规则，或资格、抵扣/留抵、亏损、预缴/已缴余额没有证据时，标明待核范围；不能套默认税率、把税率交给老板随填后宣称测算完成。现有本机固定规则能覆盖的计算由工具完成，规则不支持的方案给条件、计算结构及所需专业核验，不把语言模型算式写成工具已验算结果。

按税种/所属期记录“计税依据 → 应纳 → 已申报 → 已实缴 → 尚需缴/可退及其条件 → 预计现金日期”。利润表税费、会计计提与现金支出不能互相替代；增值税留抵不是可直接花的现金，拟退税未满足条件且未获证据前不能当确定到账。预缴和汇算差额分别列示，不能把全年税额再完整扣一遍。

## 三个现金层次

1. **企业税后现金**：按具体截止日与时段，以已核可用现金为起点，逐日/周/月加入预计实际收付。受限资金单列；若期初已排除，不再重复扣。未来未支付税款按预计支付时间扣除，含税收付与净额口径保持一致。
2. **可安排资金**：在上述余额上考虑最低营运储备、已承诺付款和债务约束。储备是管理限制，不冒充已发生现金支出。期间最低现金及缺口日期比期末余额更能揭示风险。
3. **老板个人税后现金**：只有在明确交易性质、合法可分配金额/决议、实际支付及适用个人税负后才能测算。企业现金不等于可分红利润，可分配利润也不等于马上可支付现金。

可复算结构：

```text
期末企业现金 = 期初已核可用现金
             + 期间预计实际流入（含税口径或明确净额口径）
             - 期间经营/投资/融资等实际流出
             - 尚未计入上述流出的预计税款支付
可安排资金 = 期末企业现金 - 尚未计入的资金约束/最低储备
```

先按现金事件 ID/日期去重：期初余额已经反映的历史缴款不再扣；流出表已含税款就不另扣；融资本金不作收入，回收旧应收不自动产生本期利润。缺关键数值输出 `unknown`/区间及补证，不能填零。区间需有依据，不编乐观/悲观百分比。

## 公私资金与方案比较

股东借款、偿还本金、工资、报销和分红分别核合同/借据、实际业务、审批/决议及支付凭证。不能把股东转出一概记分红、把私人支出记经营成本，或把报销本身当节税办法；公司资金和个人资金的账户与用途保持可追溯。具体扣除/代扣及分配限制按组织形式、时点和现行规则核实。

给老板一张可决策表，默认比较基准、可行方案与有依据的压力情景；无可行备选时说明原因，不强造三套方案：

| 项目 | 每个方案应列 |
|---|---|
| 业务动作 | 谁在何时做什么，经营目的与可执行性 |
| 输入 | 历史基线、老板提供的选择、已核事实与待核假设分列 |
| 量化 | 收入/成本/利润、各税种应纳与支付差额、企业税后现金、最低余额/缺口日期、必要时个人税后现金 |
| 依据 | 原件/规则/工具版本、公式、现金事件表及假设变化敏感项 |
| 代价与边界 | 办理/融资等成本、资格条件、现金压力、未知值、未覆盖风险 |
| 执行与失效 | 责任人、期限、所需复核/授权；哪些新资料或政策变化需要重算 |

当前直接业务工具不提供完整的顾问税后现金规划接口。本技能可组织专项调查和有依据的模型测算底稿，税费分支使用实际规则与计算工具；不能将方案结果冒充原生规划指标、填入不存在的字段或掩盖工具不支持状态。
