# 直接业务工具与交接

此文件保留历史路径兼容，当前业务通过`direct` finance MCP。只读实际已连接工具合同和所需Skill，不手工登记来源、事实、请求或运行时任务图。模型可见内容遵守主技能的数据边界，不能因工具能读就外发原文。

## 按业务选择

| 目标 | 入口 |
|---|---|
| 核已有企业账套 | `account_context`；企业身份、账套和实例由实际库确认，不默认首项 |
| 查账簿与报表 | `finance_query`、`ledger_query`及实际可用查询合同 |
| 查记录字段 | `finance_record_contract`，按当前业务类型读取 |
| 查规则与计算 | `finance_rules`、`finance_tax_calculate` |
| 业务及年度底稿 | `finance_workpaper`、`finance_annual_workpaper` |
| 旧账迁入 | `book_import_incremental`，先预检，原来源/批次稳定；`book_import_batch`核原结果 |
| 凭证或更正 | 实际凭证和期间业务工具；授权、封账、防重复与真实人审控制保留 |

## 本机交接

先给已核账本金额、凭证/计算、规则和未决，再关联自动保存的工具调用及输入原件。保留企业/账套/期间、接管截止日、原凭证身份、来源、当前结果及真实复核记录。原件、SQLite账库和调用记录分别备份，数据库备份不自动包含外部资料。

调用和原件索引由程序记录，模型不复制内部状态或摘要登记。新证据到达后重算受影响业务，保留前后差异和旧记录；只查历史调用不能证明当前账簿未变。未知写入先查询原身份，不换批次重做。

导入成功不证明历史完整；模型分析不升级为原生税费结果。未支持的顾问计算保留工具缺口和模型参考，不能硬塞进不存在字段。实际人审、已入账、已申报和已缴各自有据，没有就写待核。
