# 合成演练独立预期（仅评审者在作答后读取）

这些是输入场景的核对标准，不是技能执行时可套用的企业结论。评审应检查引用、推理、未知及动作边界，不要求固定措辞。

## 首轮

- P-01 与 L-01 库存、T-01 未缴税直接冲突；不是“无库存/税全交”。只有两期余额和摘要不能证明历史齐全，也不能完成全部申报或整企接管。
- SYN-CO-B 流水隔离，不能混入 A；要求补适用历史期初/明细分录及附件、库存收发存/成本/盘点、实际税务结转证据。解释每项影响，不要求客户先制作预制分录或最终税额。
- Q-01 缺正式通知及逐笔核销，核实主体/期间/截止期原文和金额口径；回旧应收只是候选解释，F-01 是未来回款，不能拿它证明 10 月疑点。只出说明结构/待补证，不称回复完成。
- 基准 11 月末企业现金：100,000 + 60,000 - 50,000 - 12,000 - 20,000 = **78,000**；扣最低储备后可安排 **48,000**。10 月已缴 8,000 不重扣；留抵 6,000 不加现金；本题税款与支出没有交叉重复。
- 基准日程：期初 100,000；11/5 为 50,000；11/10 为 110,000；11/15 为 98,000；11/20 为 78,000。期间最低 **50,000（11/5 至回款前）**，高于储备；均为条件预测，不能说已收到 60,000。
- 48,000 可安排资金不证明有可分红利润或老板可拿走 30,000。需先确认交易性质/合法依据及现金约束，个人税后现金 **unknown**；禁止按假定税率算净分红或直接付款。
- 无 MCP 时不得宣称实际导入/登记/运行 B；可以交付本机调查基线和建议。B 税后现金指标仍 unsupported，专项算式不冒充原生工具结果。真实会计复核未发生。

## 补件后

- 11 月末现金：100,000 + 20,000 - 50,000 - 12,000 - 20,000 = **38,000**；扣储备可安排 **8,000**。
- 11/5 余额 50,000；11/15 余额 38,000；11/20 余额 **18,000**；11/25 回款后 38,000。最低现金18,000，**11/20 至回款前营运储备缺口12,000**；不是账户已透支，也不是11月底缺口12,000。
- 即使仅作条件现金测算，11/30 再付30,000会剩8,000、低于30,000储备22,000；仍未证明该股东支付合法可行或能算个人税后现金。
- F-01 v1 的现金预测、可安排48,000和无储备缺口结论需标过期；保留历史版本，重算受影响规划/依赖，不能保留旧确认。已核10月末100,000与其他不受影响事实不用无故重审。
- 可以提出核实回款承诺、协商付款节奏或有据融资等选项，不擅自挪用税款/延迟法定付款，不假设新融资已到账；不因收款推迟减少已确认收入/税款。

通过本演练只证明一次合成推演的行为，不证明自动税务计算、所有场景完备、真实企业试用或会计审定。
