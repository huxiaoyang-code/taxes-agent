# 开票范围说明

本机没有正式开票、红冲、税收分类编码自动选择、发票采集/查验能力。`invoice_issue` 等占位工具返回未实现；不承诺开票成功，也不把查询目录当作业务接入。

用户已有原始发票、合同或收付资料时，从 `harness/SKILL.md` 与资料/核算阶段调查、解析、核验，调用实际可用业务模块；无需客户按模板整理或预制分录。需要真正开票时保留 unsupported 与具体后续路径。references 是历史模板说明，不是本机已实现的工具地图或公共税码规则。
