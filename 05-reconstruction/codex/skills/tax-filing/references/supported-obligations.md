# 中国税费义务目录与支持边界

本目录对应taxes-agent的29个义务ID，便于选中所需规则。目录存在不代表全场景已实现，也不保证本次原件满足条件。每项程序状态均为**有限固定分支**；实际金额状态以本次`finance_rules`、`finance_tax_calculate`或`finance_workpaper`返回为准。

| 义务ID | 名称 | 已有分支与主要边界 |
|---|---|---|
| vat | 增值税 | 境内普通交易及已核进口；跨境、特殊差额等仍有限制 |
| vat_prepayment | 增值税预缴 | 原项目、预缴地及真实收付；地区和分包等条件需原件 |
| corporate_income | 企业所得税 | 实际利润预缴与全年原件调整；年度计算不等于年度流程完成 |
| business_income | 经营所得 | 查账自然人投资者分支；核定、法人合伙人、多处经营未全覆盖 |
| salary_withholding | 工资薪金扣缴 | 原工资及官方社公明细；参数试算不等于正式应缴 |
| other_withholding | 其他个人款项扣缴 | 已核居民劳务等及租赁；非居民、包税、部分清偿等待核 |
| urban_maintenance | 城市维护建设税 | 税款基数、预缴地点及六税资格须已核 |
| education_surcharge | 教育费附加 | 整期销售、税款及减免资格；不得只取单笔业务推定 |
| local_education | 地方教育附加 | 全国基础分支，具体有效规则由工具核实 |
| stamp | 印花税 | 原合同、税目、含税列示及优惠资格 |
| property | 房产税 | 已核从租分支；从价、免租仍需已支持地区原值规则 |
| urban_land | 城镇土地使用税 | 当前列明北京分区参数；不能自动用于福建漳州 |
| vehicle_vessel | 车船税 | 全国船舶及列明北京乘用车；部分年度及地区减免有限 |
| consumption | 消费税 | 列明国内生产销售税目；不代表全部环节与产品 |
| resource | 资源税 | 国家固定率列明资源及优惠；地区浮动税目未全覆盖 |

| environment | 环境保护税 | 列明污染物、固废、噪声；复杂条件与地区待核 |
| deed | 契税 | 逐省基本规则及普通企业购置；住房与特殊减免另核 |
| land_appreciation | 土地增值税 | 列明旧商房评估法；开发清算、地方预征等待核 |
| farmland_occupation | 耕地占用税 | 列明国家设施分支；普通厂房地区参数仍有限制 |
| vehicle_purchase | 车辆购置税 | 列明国内购入及合格新能源；进口、自制等待核 |
| customs | 关税及进口相关税 | 列明税则、原产地与厂商；其他税则年度和贸易有限制 |
| cultural_construction | 文化事业建设费 | 实际税期及列明中央预算优惠；地方归属待核 |
| union_funds | 工会经费 | 已建会普通拨缴与受益期计提；筹备、代收返还等待核 |
| tobacco | 烟叶税 | 合法单位列明烟叶收购及采购成本；依原证据 |

| social_insurance | 社会保险 | 官方核定和付款核销；任意参数只可试算 |
| housing_fund | 住房公积金 | 官方核定和付款；公开地区公式尚有未接分支 |

## 本次状态

- 已计算：只引用实际返回的金额、范围、期间与来源，不扩大到整期或全部税种。
- missing/unknown：列具体原件或判断缺口；没有due不补0。
- unsupported/uncovered：指出实际业务或地区未覆盖，保留模型参考或专业复核路径，不能编事实规避。
- not_applicable：须有适用事实支持，不能因原件没提到就判不适用。

工具实现期间与法律生效期间不同；查看每项实际来源、条款、有效期、地区和资格。日常报告展示金额、计算与规则，后台自动保存完整调用和原件索引。上述范围按现有固定目录记录，后端变更后同步本表并核验；税率公式仅由工具维护。
