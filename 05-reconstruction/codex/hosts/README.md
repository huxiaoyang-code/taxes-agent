# 选择财税 Agent 应用

Pi、Claude Code、dsh 和 ZCode 都能作为任务入口，调用同一本机财税后端，处理账前核对、凭证、对账、税费和报表。选择已安装或熟悉的应用即可，业务能力不按应用划分。

| 应用 | 适合的使用方式 | 本项目提供 |
|---|---|---|
| [Pi](pi/README.md) | 使用 Pi 交互会话或任务文件 | 启动器、财税扩展和连接检查 |
| [Claude Code](claude-code/README.md) | 在 Claude Code 工作区交代业务 | 绑定启动器、生命周期上下文、局部 memory 隔离和工具审批配置 |
| [DeepSeek Harness / dsh](dsh/README.md) | 通过 dsh 命令行运行明确任务 | 可显式加载的财税与技能配置 |
| [智谱 ZCode](zcode/README.md) | 在 ZCode 工作区或命令行处理业务 | 工作区财税连接和技能目录配置 |

从[配置与启动](START-HERE.md)连接本机后端、指定账库和资料目录，再按[业务技能](../../../plugins/finance/README.md)选择任务。模型服务由各应用配置，生成器不安装应用或代填账号凭据。

处理已有账套时通过 `start-business-session.mjs` 绑定实际企业、本期与资料/记录目录，并自动初始化历史口径；同一摘要→方法→案例/依据协议供四宿主读取。配置生成、只读 `--check`、显式 `--prepare-only` 与真实模型业务分别验收；逐项操作及各宿主自动刷新的实际边界见 [企业记忆说明](BUSINESS-MEMORY.md)。

成功MCP写入/已绑定计算后台同步，按本期对象和来源读当前方法，不要求维护刷新状态。该说明还提供两企业两期的干净阳性现场和R01–R14逐点核对入口；最终源码哈希、真实宿主/模型及真人审阅分别对照，配置或合成TTY不是业务批准。
