## 三、用户本轮已确认的业务范围

1. 本机单用户，一名操作者可对多企业多账套批量办理；不做 SaaS / 多租户 / 账户权限平台；全国属首版，福建漳州先验收，漳州通过不等于全国完成。
2. 两套准则都要：小企业会计准则、企业会计准则。
3. 办税员登录与授权企业管理、企业与账套选择；首次旧账导入与后续连续月份接续做账；科目期初 / 凭证 / 过账 / 计提摊销 / 结转结账；辅助核算、银行流水处理与银行对账。
4. 内部报表（资产负债表、利润表、现金流量表、科目余额表、明细账）与税局要求的财务报表文件；**Excel 与 PDF 都必需**，现有 CSV 保留但不限定仅 CSV。
5. 发票采集、查看下载、开票、红冲及结果核对。
6. 企业实际适用的各税种：计税、核对、正式申报、结果与回执核对，含应办月 / 季 / 年及更正业务；覆盖清单由研发整理交项目经理逐项验收。
7. 个税：工资薪金、劳务报酬、经营所得与年度汇算全部包含。
8. 正式缴款、社保、非税全部纳入首版；能办理相应的应办申报与缴费事项，每次办理有结果与凭据核对，申报状态与缴款状态分别核对，申报成功不等于缴款成功。
9. 二十家企业实际同时处理是硬目标（一个办税员名下二十家、多办税员合计二十家两种模式分别验收），资料不混企业、不重复办理，支持一次批量发起、进度与逐企业结果、失败继续处理；提供命令行批量操作入口，可批量发起、查看进度结果并继续未完成事项，不规定命令形式或技术选择。
10. 敏感资料仅按操作者授权用于相应业务，不向无关人员或服务披露；正常办理按授权提供必要资料，资料保护不妨碍已确认的正式申报与缴款；操作可追溯、备份可恢复；资料不足明确提示，不凭空补零；重复操作不重复办理；不确定成功时先核实。
11. 开票 / 红冲 / 正式申报 / 缴款前由操作者确认，可按明确批次确认。
12. 速度基线：用户原话为「五个熟练会计一个月大概报 200~300 家」。这是业务基线、五人合计，不是实测或行业统计，不得按每人或每小时换算。以区间上沿为建设基准，最终在可比条件下**一名操作者配合产品每月正确完成企业申报数大于 300 家**；只超过 200 家不算达标。
13. 二十家并发与月产出**分别验收**；前期用演示 / 合成样本验证功能、并发、正确性、失败恢复与容量依据，不得提前声称真实月产出达标；后期在获授权企业中分别验证一个办税员名下 20 家和多办税员合计 20 家的"实际同时处理"，并以一个可比工作月的完整数据验收产出，前期演示或合成结果不替代真实并发与月度产出证据。
14. 研发需提交未达标应对方案（不足情况、影响、可选改进或替代办法、临时业务连续办理措施、负责人与重新验证办法）；用非技术表述，临时人工处理单独计时计量，不冒充产品产出。
15. **自动点击浏览器 / 点击脚本路线已被用户明确永久否决**，不再作为做法或备用方案。
