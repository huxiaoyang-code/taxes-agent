## 本包实现与支持边界

复用 tax-gateway、agent-tools 和既有 finance MCP 链，新增以下 5 个受控工具；默认真实适配器仍为空，不连接真实税局。

| 工具 | 当前实现与限制 |
|---|---|
| `tax_session_verify` | 验证适配器企业作用域，返回安全引用；未配置真实适配器时明确拒绝 |
| `tax_resource_collect` | 受控 `queryPage` 合成契约、业务结果 / 作用域核验、有界分页与限量重试；返回 `metadataOnly=true`、`evidencePersisted=false`，**不保存真实业务记录** |
| `tax_resource_coverage` | 返回作用域 / 期间的进程内覆盖摘要；中途失败丢弃整个资源覆盖，`count=null`、`complete=false`，不保留部分成功或支持断点恢复 |
| `tax_account_set_link` | 关联操作者指定的已有账套，进程内引用；不新建、不导入、不自动核对企业，`identityMatched=false` |
| `tax_preparation_build` | 仅读取已关联账套可得性与计数，生成缺项 / 未校验摘要；无已验证官方规则或表单，无字段映射产品闭环，始终 `blocked`、`submittable=false` |

`sourceRef` 是**进程内采集元信息引用，不是持久、可解析的业务证据索引**，不能与本轮独立本机观察索引混同。新业务资源目录有 10 类，但采集适配契约仅允许既有 5 类（`identity`、`authorized_enterprises`、`enterprise_profile`、`tax_assessments`、`declaration_status`），其余未支持；默认无适配器时这 5 类也不代表真实可用。历史 / 发票 / 缴款在准备模块为 `needs_assessment`，不强制全取，也不由待办推全义务。

旧数组静默截断 500 条改为明确拒绝，分页契约不以截断返回全量。首次 verify 前的并发乱序、失败后的旧覆盖残留及 sessionId 空格别名均已修复并补回归。PR #19 仅选择性复用回环 Host / Origin 与无 CORS 边界，未合并其 DOM 采集。**旧 login / status 的 enterprise DTO 未做整体隐私改造**；本包新工具的安全摘要约束不能外推为全部历史接口已适合向模型输出真实信息。
