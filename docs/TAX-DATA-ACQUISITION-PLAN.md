## 应办事项与表单字段如何确定

以“企业 + 事项 + 所属期 + 申报 / 更正版本”为核对单位，综合**税费种认定 + 当期待办 / 已报状态 + 必要历史 + 官方有效规则 + 企业事件事实**形成候选。不能单凭菜单、待办或历史申报推定全部义务；系统未显示待办也不能直接认定无义务。

每个候选分别记录“应办 / 不适用 / 待确认 / 资料不足”，保留判断理由、证据引用、地区、规则发布日期 / 生效与失效日期、所适用期间、表单版本。历史期间适用历史有效规则；新规则、优惠到期、认定变化或更正会触发重新判断，不用当前页面文字替代政策适用核对。

**财务报表报送、纳税申报、缴款分成独立事项和状态**；预缴 / 年度汇算、原申报 / 更正也分别处理。财报文件生成不是报送成功，申报成功不是缴款成功；开票、红冲等另有外部写操作确认，不在只读盘点中执行。

| 映射记录 | 必填内容与校验 |
|---|---|
| 事项 → 表单 | 企业引用、所属期、地区、税种 / 事项、表单及版本、正常 / 更正类型、有效规则引用 |
| 表单 → 字段 | 字段路径、含义、类型 / 单位、必填条件、期间、原值 / 规范值引用、计算或取值规则 |
| 字段 → 来源 | 税局当前响应 / 本地账套 / 用户补项三选或组合；源记录与版本、采集时间、冲突及缺项状态 |
| 预填 → 校验 | 资料齐全、类型 / 日期 / 金额、期间一致、表内 / 表间勾稽、账表税差异、前后期结转、优惠条件 |
| 缺项 → 补齐 | 明确缺什么、为什么需要、从哪里补、影响哪个字段 / 事项；不得用合成数据替代真实输入完成申报准备 |

首条闭环从盘点结果中选**当前公司、当前待办期间内资料与接口可证实的事项**，由用户确认选择。如无可完成事项，交付准确缺项与阻塞证据，继续必要取数 / 补项，不制造可提交状态。

## 两遍采集、证据分级与失败处理

第一遍为真实发现 / 限量响应，第二遍为最小后端的独立实际请求。分别保存本机批次引用、时间、正常参数、范围、分页完成标记、计数和业务结果；同一有效会话是复用本机鉴权上下文，不是把 Cookie 写进契约。会话失效时停止，用户人工重新登录后记录新会话批次与可比范围，不伪称沿用原有效会话。

| 证据级别 | 能证明什么 |
|---|---|
| 历史线索 | 旧 checkpoint 的路径 / 字段 / 错误提示，只指导待复验候选 |
| 当前已观察 | 当前菜单或请求存在，不能证明业务成功、完整数据或无副作用 |
| 首次成功 | HTTP、业务码 / Error、schema、身份作用域均通过的本次真实响应 |
| 二次采集验证 | 最小后端再次实际请求成功，分页 / 日期 / 范围可核对；时间变化说明清楚 |
| 产品接线 | 经本机产品路径完成取数、处理、字段追溯与业务验收，仍按地区 / 事项记录覆盖 |

不得只以 HTTP 200 / `Data` 存在判断成功。空数据要区分确实无记录、参数不符、无权限与业务失败；分页中途失败不能标全量。认证过期或身份不一致停止当前采集；超时 / 限流按有界次数处理，重试只适用于已证实无副作用的读取。

SSO 签票、标已读、身份切换可能改变状态，不属于无副作用读取。发现这类依赖先反馈必要性与范围，不默认纳入白名单。旧 checkpoint 的路径拼写、封装风格与错误码只作待复验，不猜补完整端点。

## 本机实现与数据边界

最小后端只支持已证实的受控操作及允许的企业引用、日期、分页等正常查询参数；不接受任意 URL / 任意头透传。每次执行校验当前身份作用域，模型规划不能扩大目标企业、期间或动作。LLM 使用 schema、缺项状态与安全引用规划，实际取数、计算、归一化和对账在本机处理。

非凭据业务响应可按用户要求保存到本机受限且 Git 忽略目录（候选 `06-workbench/data/tax-acquisition/`，落地前核实忽略与访问边界）。认证头、Cookie、token、票据、OTP 仅留本机会话，不进入业务采集产物或日志，不发模型。若业务响应混有认证字段，先在本机剔除再作为业务材料保存；不导出含凭据 HAR 作为交付。

模型 / subagent 仅接收字段 schema、脱敏或合成样例、成功状态、计数、覆盖范围、失败类别，不回显真实企业身份或账簿原文。真实数据仍在本机参与计算，不能用脱敏或合成样例冒充真实处理。自动回归只用合成临时库；自动点击 / 点击脚本路线继续禁用。

正式提交前冻结预填材料、来源版本、规则 / 表单版本及校验结果，**仅在本机可信预览**向用户展示企业、事项、期间、金额 / 关键字段及差异供批次确认，不经模型聊天回显真实身份或账务原文。确认只对应该冻结版本；资料 / 规则 / 目标改变则重新校验并确认。提交后分别保存请求业务标识、受理状态、回执引用和错误类别；超时先查状态，未确认未受理不得盲目重提。扣款、更正 / 作废、备案变更另行明确确认，不随普通申报确认自动执行。

具体税率、优惠和事项适用只在对应企业 / 所属期有有效官方依据与事实后确定。本方案不预设税负，不按目标税负倒算账务。
