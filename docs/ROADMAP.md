## P2 · 发票与申报（后期，自研或接第三方）

### 必须完成：全国电子税务局办税员登录与信息获取

第一期只交付统一适配器接口、31 省区市 + 5 计划单列市路由目录及契约测试，真实接入数为 0。下一阶段应先选一个可授权联调地区，打通凭据引用、人工验证、授权企业选择、信息查询及退出，再按地区分批扩展；每个地区分别记录协议核实、实际登录和取数验收。真实登录、凭据生命周期、超时/重试、会话清理和覆盖矩阵通过后才能标记该地区可用。不能以目录存在替代全国适配完成。

接口说明见 [TAX-INTEGRATION](TAX-INTEGRATION.md)。该目标为用户确认的必做项；实际账号与联调授权在该阶段另行落实。

| 项 | 说明 | 触点 |
|---|---|---|
| 发票采集 / 查验 | 对应 `invoice_collect` `invoice_file` `invoice.detail` | `agentTool()` 分支 |
| 开票 / 红冲 | `invoice_precheck` `tax_code` `issue` `red_*`；需税局或服务商通道 | 同上 |
| 全税种申报 | `declaration_query` `tax_declaration_query`；增值税/附加税/所得税/印花税 | 同上 |
| 个税申报 | `individual-income-tax-filing` 子智能体 | 同上 |
| 其余规则正文 | 记账与旧账导入本轮补齐；发票、企业申报、个税等仍待接入后完善 | Skill 文档 |

> 合规提示：开票与申报必须通过合法通道（电子税务局 / 持牌服务商），
> 相关能力不实现则继续返回 `not_implemented`。
