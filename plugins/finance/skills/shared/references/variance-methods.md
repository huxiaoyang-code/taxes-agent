# 差异分解与说明模板

改编官方variance-analysis的驱动分解、桥接和文字说明方法。以下是财务分析结构，不是中国税率或税额计算规则。

## 选择分解口径

| 驱动 | 所需原始明细 | 核对方法 |
|---|---|---|
| 价格与数量 | 同口径商品/服务数量和单价 | 明确固定基准及交互项分配方法，各驱动加总回总差额 |
| 费率与结构 | 实际费率、业务组合及基准 | 区分单价变化与组合变化，不重复解释同一金额 |
| 人数与薪酬 | 实际人员期间、薪酬和调整 | 入离职、实际支付、奖金及跨期分开，个人资料本机保护 |
| 支出类别 | 科目、部门/项目及业务明细 | 区分数量、重分类、一次性和期间差异 |
| 税费差异 | 实际税基、资格、政策期间及工具结果 | 原生计算与模型计算分列，不自行改税率凑结果 |

自主选择Python、表格公式或已有计算器并留存实际方法。先保留总差额，再按选定方法拆分；未解释部分明确显示。方法变动时说明可比性，不能悄悄换基准。基期为零或缺失时不生成无穷比例。

## 每项文字说明

1. 实际金额和比较基线、差额及方向。
2. 已核业务驱动和量化贡献。
3. 原件或凭证支持，以及尚未证实的解释。
4. 持续/一次性影响、需要调查或处理的具体事项。

“费用变多因为费用增加”不是原因。同行比例、预算或阈值没有资料就不生成；重要性由本次实际企业口径决定。

## 桥接表与图

起点、每项增减、未解释部分和终点使用同一组数字，注明正负方向和单位。表格和瀑布图应能互相勾回，避免颜色或累计值掩盖差额。日常报告先金额，再结果和依据，完整调用与输入保存供深入核对。
