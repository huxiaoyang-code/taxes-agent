# 增值税抵扣选期与税负比较

<!-- 本项目于 2026-11-21 按中国财税业务改编自 Anthropic Portfolio Rebalance Review，原版及许可证见插件 SOURCES.md。 -->

用于一般计税业务。会计只需给出整期任务或要求比较方案。Agent 从获准资料中找出可选事项，拟定并修改逐票选择，计算后交给会计复核。单独要求核对现状时交付现状和差异即可。

1. **界定比较对象。** 固定企业、账套、所属期、信息截止日、推演结束月和政策版本。读[账套口径](../../company-baseline/SKILL.md)，核约定税种、分子、分母、单月／年初累计、阈值方向、生效期间及出处。区分客户实际约定和行业参考。两种税负都算，按客户约定推荐。口径不明时先算两种，只有会改变选择时才问一个具体的决策问题。
2. **建立共同基准。** 核上期实际留抵、未用票清单和已申报数据。逐笔核本期已发生义务的已开票及未开票销售。把截止日前已确认、已申报、已转出及更正记录按票和所属期锁定。逐票保留销方及号码、开票日、首次可知日、原始用途、合法可选起止月、证据和剩余额。未用票与已经申报的留抵各建一栏。用[数据复核角色](../agents/vat-data-review.md)找出哪些金额仍受冲突影响。
3. **核现实窗口。** 按[官方政策核查](official-policy.md)查实际适用条款、过渡期和税务账户状态。开票、收件、用途确认操作日、正式勾选所属期和申报日期分别取。次月首次取得资料，只有在本次截止日前可知、原票已于上月开具且门户证据支持上月仍开放时，才试算上月。次月才开具或已有申报锁的期间排除；历史更正另留原回执。混合用途、红字及转出的原票、处理期和余额逐项查证，冲突票暂列，继续比较其余票。小规模、简易计税和不适用事项回到[税种入口](../SKILL.md)。
4. **提出选择并逐次验证。** 先比较合法票尽早抵扣对下次付款的影响，再根据约定阈值、经营现金或年度差异提出保留哪些票、何月再用。从当前宿主的工具清单或按需搜索确认一般计税规划工具可用后，先读 `finance_record_contract(recordType=vat_planning)`，取回候选并翻完分页。用匿名票引用逐张给出所属期，保持相同 `asOf`、`through` 和 `expectedBasis` 反复试算。只有已支持该合同的工具才调用 `finance_vat_plan({target,inputPath,asOf,through,baseline,plan,expectedBasis})`。无此工具或存在未覆盖事项时，用有原件定位的表格或脚本完成同口径复算，标明未覆盖条件。一个方案中的同一票只能使用一次，所有方案用同一销售、预测、留抵起点、规则和截止日。
5. **比较与修正。** 使用[算式及假设](vat-calculation.md)逐月滚算到年末和下一可用期，同时算单月及累计税负，核各期分母、留抵、预缴抵减前应纳、抵减后应补及预计付款月。测算当前与备选差额，解释偏离约定多少个百分点、哪些票造成、最早何时收回现金差异。新事实改变可用票、规则或预测时从受影响月份顺推并保留原版本。如果没有组合达到约定，交付最接近的**可证明**结果；只检查过部分组合时说明已比较范围，避免把局部较好方案当作全局最优。
6. **形成决定。** 在[比较表](../templates/vat-comparison.md)列金额与依据，按[选票备忘](../templates/vat-decision.md)记录推荐、备选、尚待确认与失效条件。只有实际门户回执、申报表或付款证明能分别改变勾选、申报和实缴状态。会计交付按[申报准备](tax-organizer.md)接续；更广的经营、租赁和股东现金问题见[合法方案与税后现金](planning-cash.md)。

复核取数时，用实际调用编号打开同版 `vat-planning-evidence.json`。其中保留原件摘要、表头或原行、字段位置及判断依据。交付税款现金简报时，先在符合客户约定的已比较方案中核年末现金及跨年付款，再说明相同年度效果下近期哪一笔可以少付。
