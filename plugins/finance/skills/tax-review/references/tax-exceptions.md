# 易错事项与更正路径

<!-- 本项目于 2026-11-21 按中国财税业务改编自 Anthropic `reference/gotchas.md`，原版及许可证见插件 SOURCES.md。 -->

| 发现的情况 | 查什么、如何修正及顺推 |
|---|---|
| 已开票销售合计低于已履约交易，或预收与租期错配 | 追合同、交付、约定收款及实收、先开票等证据，按适用税点重建已开／未开票销项。租期只随真实合同事实变化。对账税期间差异另作桥接。 |
| 次月收到上月票，系统中另有确认导出 | 保存开票、首次可知、门户选期起止、已确认与已申报属期。上月是否可选须有相应证据。已报的历史更正保留原申报和更正回执，不能修改所有方案的历史。 |
| 同一发票多行、多次导出，或出现红字和转出 | 按开具主体／号码及明细行、原票关联和状态去重，核有效税额、此前抵扣额与冲减期。不能一边净额入数一边再减同笔。若无法识别原票，隔离有争议的余额。 |
| 混合用途长期资产 | 取资产种类、购入与投用日、单项原值、用途及占比变化、已抵扣额和调整年度。打开适用于该年度的办法及附件查分档、调整期限和年度计算，再复算当期及后续调整。关键附件或原值未核，给出有条件的差额，不整张放行或一律转出。[长期资产进项税额抵扣办法](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5247500/content.html) |
| 非应税交易的规则或口径变化 | 分别核交易性质、发生日、是否已处理及处理日，对读新旧条款、施行日和过渡条款。只有适用的版本进入测算，保留已有结论及受影响的票／期间。[非应税交易等事项公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5252024/content.html) |
| 地区发布新申报表 | 分别核地区公告、本企业是否属于主管机关确定的范围、申报属期和表式版本。上海试点的地域标签本身不能证明入选；主体通知未取得时只将新表适用列待核。[上海市申报试点公告](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/zzs/202606/t480523.html) |
| 年中迁入、跨年、重复回执 | 先圈定实际覆盖期，验证期初累计和逐月重叠。跨年税负重新累计，余额和未付跨年；按业务及回执版本核销，保留同笔多份来源。 |
| 预缴、留抵、申请或实收退税混记 | 完税／可抵项目及抵减记录决定预缴余额，原申报与核准手续决定留抵调整，原银行回单决定实收。分别标注可申请／已申请／已批准／已到账，按各自生效日影响税额或现金。[留抵退税政策](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5242450/content.html) |
| 目标无法达到、政策附件未读或只有平台汇总 | 披露已试组合、最接近值与仍缺条件；只阻断受影响的金额或选择。核实新材料后从最早受影响期重算留抵、预缴、未用票和付款，保留前后差额。 |
