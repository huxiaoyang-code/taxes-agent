# 原件、连接器与取数字段

<!-- 本项目于 2026-11-21 按中国财税业务改编自 Anthropic `reference/connector-queries.md`，原版及许可证见插件 SOURCES.md。 -->

先搜已授权本机账库、历史申报导出和绑定原件目录。能从账和原件得到的事实由 Agent 自行读取；需要补件时点出具体期间、资料及影响金额。在 host 有委派能力时将一行分派给[只读提取角色](../agents/tax-source-extract.md)。各宿主按实际可用的工具发现和本机权限读取。

| 来源与实际入口 | 取数范围与字段 | 可以核对什么；缺失时如何继续 |
|---|---|---|
| 账套、总账与明细，`account_context`、`ledger_query` 或授权导出 | 主体、已过账期间、收入及应交税费明细、余额、凭证日期号、借贷方向、结转 | 科目净额与法定表行逐项桥接。只给余额时，向期间明细／账簿导出追取发生额。 |
| 企业约定及上期累计，[账套基线材料](../../company-baseline/references/materials-and-save.md) | 生效月、税种、应纳／实缴、分子分母、所属期／付款期、上年末与本年起始覆盖 | `finance_baseline_materials` 按披露合同取历史，有重叠的累计和明细选一条序列。 |
| 合同、签收、销售台账、收款与发票 | 履约、约定付款、实收、开票、原票红字关系、金额／税额、税点证据 | 核已开票和未开票应税销售；收款可为结清应收或预收，须追业务原件。 |
| 购进及用途、税务账户导出 | 销方与号码、购方、税额、开具／收到、首次可知、可选窗口、用途、已确认属期、可更正状态 | 月份精度原样保留。进项台账不证明已经用途确认。多行税率按票明细合计，重复导出只取一次。 |
| 申报表、附表、回执、退税决定 | 税种、属期、版本、受理状态、应纳、已抵预缴、期末留抵、获准退额 | 截止日内取有效版本并保留原申报和更正轨迹。账户选择不能充当申报受理。 |
| 完税凭证、银行或支付流水 | 税种、属期、项目、凭证号、收付日、金额、税务核销、实际入账与银行唯一引用 | 复核分次、跨期、同一回执多渠道及未匹配记录。只有申报表时保留实缴未知。 |
| 已批准经营预算、合同收付款表和纳税日历 | 预测生成日、覆盖期、现金日或区间、单位、假设、来源版本 | 取截止日前可知的预测；有实际结果后单独更新版本。 |

每个来源保留账套短引用、业务日期、首次可见日期、版本／摘要、页／表／原行和覆盖缺口。扫描件标记页和字段，汇总有数而明细缺失时联系原提供方补分项。外部检索使用公开政策词，客户原件及身份留在获准本机路径。
