# 增值税算式、假设与复算

<!-- 本项目于 2026-11-21 按中国财税业务改编自 Anthropic `reference/calculation-assumptions.md`，原版及许可证见插件 SOURCES.md。 -->

以下关系用于核对按一般计税、境内业务且无其他特殊调整的测算。先用[官方政策核查](official-policy.md)确认适用项目，遇简易计税、出口、差额计税或特殊调整，按其适用条款、表式单独核算，明确受影响金额。币种和金额精度按原表保存；按规则规定的计算与舍入层级复算，显示百分数的舍入留到比较之后。

- **抵扣前提。** 核上期真实申报留抵，已锁进项、可选票和待核票逐票清点。只将本期实际已确认或方案合法拟选的进项各纳入一次。未用票期末额为期初未用票加本期新增合规票，扣本期使用和确有依据的作废／红字／资格变动。年度切换后继续承接尚存余额。
- **本期一般计税。** 在上述有限范围内，差额＝本期销项＋本期进项转出－本期可用进项－上期留抵；抵减预缴前应纳＝正差额，负差额形成期末留抵。转出只有在尚未计入进项净额时才加一次。存在其他表内调整、退税核减时另列发生依据、生效期和实际调整栏次。账面计提另取凭证及科目变化。
- **预缴。** 用可抵项目、属期、完税凭证和此前实际抵减核当期可用额，累计抵减不能超过有据可用额。按当期规则抵减后得到应补，并将有依据可结转的余款接至下期。历史已付款不重复列为当期应补。申报应补、实际缴纳及申请退税分别从各自证据取得，未获证的退款不能形成实收。
- **税负。** 以客户当期约定确定分子与可比不含税销售额。若约定采用抵减前应纳，单月＝本月抵减前应纳／本月可比不含税销售额；年初累计＝（已核至上月的同口径应纳合计＋本月应纳）／（相应销售额合计＋本月销售额）。销售额为零时该比值无定义，负数或口径变化时说明可比限制，仍列税额。累计已核部分只有月税负率而缺少原分母时不能累算。实缴口径需有实际付款及属期关联，税款预计付款不得计入实缴税负。
- **现金及情景。** 用同一截止日可知的销售预测、申报频次、支付日期、留抵与预缴起点，分别运行原计划和建议计划。逐月滚动，指出相同终点的差额以及尚未回收的余额；未来缺乏销售预测时给出回收所需条件，避免指定虚构回收月。

记录每项假设、对应来源日期／原表行、采用的公式或工具版本、结果是否条件成立。单期条件试算的输入见[汇总条件试算](summary-calculation.md)。计算器未覆盖新规时，保留原结果、官文条款和独立复算差异。
