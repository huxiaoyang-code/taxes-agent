# 当期准备与全年会计交接格式

<!-- 本项目于 2026-11-21 按中国财税业务改编自 Anthropic `reference/output-formats.md`，原版及许可证见插件 SOURCES.md。 -->

按任务范围生成会计能在本机打开的报告及所需明细，首页写企业、账套、税种、身份、币种、所属期、信息截止日、已核账表、版本和重要未决。把报告路径或可打开入口交给操作者；证据表索引至原票、账、申报表栏次和缴款回单。以下表按真实记录填行。

## 当期准备

| 税种／方法／申报频次 | 销售净额／计税依据 | 销项／可抵进项／转出 | 期初与期末留抵 | 抵减前应纳／预缴已抵／应补 | 已申报／已缴与日期 | 差额、来源与期限 |
|---|---|---|---|---|---|---|
| 按法定申报期间列，季内附逐月来源 | | | | | | |

附逐票依据、备选方案、月度及累计税负、预计／实际付款、关键假设以及变更触发点。按凭证、账簿、报表和申报依据对相同期间核数，有差异列调节项目及来源。逐笔说明“已计算／已勾选／已申报／已支付”相应证据。给会计应办事项、谁能提供、期限和影响金额。

## 全年交接

| 税种及申报期 | 账簿／凭证 | 申报表版本／回执 | 税额／调整及差额 | 预缴抵减／缴款／退税回单 | 期末留抵／未用票／未缴 | 异常与责任人 |
|---|---|---|---|---|---|---|
| 全年逐期列，标注缺期或换身份 | | | | | | |

附有效申报与更正索引、原件清单、凭证异常、跨源去重说明、年度所得税资料（如适用）、未决金额、处理期限及次期承接。会计可按每个差额定位两端来源。

## 复核与后续

| 变更时间与资料版本 | 受影响票／属期 | 更改原因／规则条款 | 更改前后及后续现金差额 | 待补证、责任人、到期日 |
|---|---|---|---|---|
| | | | | |

记录下期起点（留抵、未用票、可抵预缴和未付），确认哪些客户长期约定可继续沿用。将本期选择与实际回执留在本期底稿。必要时附本机计算调用编号或文件名，只有实际签署／受理／入账时填复核人与状态。
