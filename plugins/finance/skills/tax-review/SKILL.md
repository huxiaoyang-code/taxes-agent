# 中国税费核对与申报依据

本技能按官方finance工作流格式新增，来源见 [SOURCES.md](../../SOURCES.md)。本机工具用于核对计算和提供申报依据；没有真实税局登录、申报提交或缴款能力。

做账前需要先核对采购、进销项与实际资金、向老板问询和补件时，进入 [账前整理与核对](../prebook-review/SKILL.md)。其一般／小规模增值税条件试算不代替本技能的其他税费或完整申报依据核查。

## 工作流程

### 1. 明确企业与本期事项

核实主体、账套、期间、币种、会计准则、纳税身份、申报频次、适用资格及实际地区。福建漳州不自动等于市区，也不证明地方优惠或参数已支持。客户提供原件，由Agent整理和判断，不要求客户先算税或写工具内部模板。

### 2. 按需读取规则与业务合同

按需从`finance_rules`或已核官方原文核实税种、主体、业务、地区、有效期间、政策来源及限制；选择原生计算器时用`finance_record_contract`查所需合同。合同未完整不等于引擎未实现，也不等于企业事实缺失。仅加载对应参考：

| 事项 | 参考 |
|---|---|
| 一般纳税人销项、抵扣及留抵 | [一般VAT](references/vat-general.md) |
| 小规模季度、专票及补记收入 | [小规模VAT](references/vat-small.md) |
| 企业所得税预缴与年度调整 | [企业所得税](references/corporate-income.md) |
| 工资薪金累计扣缴 | [工资个税](references/salary.md) |
| 合同与印花税 | [印花税](references/stamp.md) |
| 全部税费义务及地区限制 | [支持范围](references/supported-obligations.md) |

### 3. 计算与账目勾稽

Agent可根据已核规则自主用Python或表格计算，保留公式/脚本、原件定位与条件。原始业务、选定税费和全年计算也可分别选择`finance_workpaper`、`finance_tax_calculate`、`finance_annual_workpaper`；原生合同只约束所选工具，不要求客户提供内部ID或manifest。工具按真实分支计算，不把一条公式运算等同全部资格已核。凭证交易税额、账面计提、本期法定应纳、实缴和差额分别读取，缺失项保留原生状态。

带来源汇总也可自主选独立`finance_tax_summary_calculate`作条件试算，按需读`finance_record_contract(recordType=tax_summary)`的支持范围、字段和原件绑定示例。它不需要编造业务记录，不替代完整账核验；见[汇总条件试算](references/summary-calculation.md)。

模型计算与原生计算均须有来源；如工具不能表达某项业务，保留工具缺口并给可复算的独立计算，不编造认证日期、季度明细、优惠资格或银行核销记录来让工具通过。原生结果与独立核对不同则两者保留，明确调查对象。

### 4. 复核

检查所属期、计税依据、资格与减免、发票及抵扣用途、期初承接、累计和季度口径、账税差异以及实际支付证据。一般/小规模与小型微利是不同认定，不能互相替代。地区参数和政策有效期以已核官方来源及事实核验，不复制上游或本Skill中的默认税率。

### 5. 输出

先列账本及税费金额、待核差额；凭证/抵扣清单、计算、规则、条款定位及本期适用事实按需查看，后台保留本期为何这样处理的依据。完整账期使用系统固定卡片，展示期初未缴、本期计提/代扣、本期缴纳和期末未缴；净计提与实缴不直接等同科目贷借方发生额。未决事项保留可见，工具调用和输入原件留在后台。每个金额标明原生结果、模型计算或待核，不把未返回due写成0；已能独立算出的金额与工具缺口分别报告。见 [报告顺序](../shared/references/reporting.md)。
