# 凭证编制

本文件由 Anthropic 官方同名 Skill 中国化改编，来源和修改说明见 [SOURCES.md](../../SOURCES.md)。连接类别见 [CONNECTORS.md](../shared/references/connectors.md)。

根据业务事实自主选择处理方法、Python/表格或已有计算器；以下步骤是工作指导，可按资料情况调整。系统自动记录调用，不需要手工登记事实、版本摘要或任务图。

## 使用

`/finance:journal-entry <业务类型> <期间>`。业务类型可为采购、销售退货、费用、资产、工资、计提或收入。币种默认仅在已核实为 CNY 时使用人民币元；期间、企业和账套均须明确。

## 工作流程

### 1. 收集业务资料

连接 `~~erp` 时取得真实账套、科目和相关明细；没有连接时读取本次获准的原件或请提供资料。由 Agent 整理，不要求客户填内部 JSON。

先明确适用会计准则、纳税身份、实际业务日期、履约与收付、发票和抵扣事实。选择原生计算器时才按需加载该业务的 `finance_record_contract`，核对字段披露完整度；不认识的字段先查合同，不猜近似类型名。只有通用结构和规则引用时标注披露缺口，不据此断言算法未实现。工具字段缺口不证明企业事实缺失；缺件只影响依赖该资料的处理。

### 2. 核对并计算

- 原始业务可用Python、表格公式或已有计算器计算并生成分录草稿，保留原件、参数语义和实际公式/脚本；选择 `finance_workpaper` 时按实际合同提供目标、原件和记录。
- 已有明确分录时用 `voucher_check` 检查金额、科目和借贷；账簿查询使用 `finance_query` 或 `ledger_query`。
- 自主计算和判断单列依据、条件及未决项，不改写原件，不把推导称作原生工具结果。
- 中国税费可选 `finance_tax_calculate`；适用规则按需通过 `finance_rules` 或已核官方资料读取，不在本 Skill 另维护税率表。

### 3. 生成凭证草稿

| 日期 | 摘要 | 科目编码及名称 | 借方（元） | 贷方（元） | 业务来源 | 状态 |
|---|---|---|---:|---:|---|---|
| 有证据的实际日期 | 实际业务 | 适用科目 | 有来源计算 | 有来源计算 | 原件定位 | 草稿/已入账 |

支持明细列出计算过程、归类理由、前期比较和需调查事项。冲回依据实际业务和准则判断，不默认所有计提次月冲回。实际编制者和复核人分别记录，没有人审不代签。

### 4. 复核

检查科目与用途、金额精度、借贷、期间、收入和成本配比、价税关系、抵扣资格、退货原批次、收付核销及重复业务。借贷平衡不证明业务正确。草稿、已过账与待复核分别列示；需要正式入账时使用真实工具及现有授权和校验，不通过 SQL 或改日志制造成功。

### 5. 输出

按 [报告顺序](../shared/references/reporting.md)先显示账本金额与差异，凭证和计算结果、适用规则与依据按需查看。完整账期使用系统固定卡片，不另写重复索引；工具调用及输入原件保存在后台。没有证据支持的金额写待核，不填零；接口未返回金额与原件缺失分开说明。

具体方法和支持模板仅在需要时读取：[按需参考](../shared/references/journal-support.md)。
