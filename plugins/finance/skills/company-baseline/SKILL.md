# 账套记忆

1. **沿用当期口径。** 按绑定的账套和月份使用宿主已加载的账套 `MEMORY.md`。如需打开文件，用宿主原生文件工具读取 `.finance/business-session.json` 的 `memoryPath`。文件尚不存在时，从账套配置和代表性已过账历史中查本期需要的事实；必要时查同一业务的合同、凭证或申报依据。
2. **只记可沿用的结论。** 核实合同期间、历史分录与实际规则是否支持口径。优先记准则、重要业务分类、进项或销项所属期、当月结清或分期。每条写适用条件、生效期、结论和简短依据索引。例如「仓库租金｜自 2026-07｜整月均匀履约时按月确认｜合同第 3 条及 7–8 月对应分录」。按需核查缺失或冲突的条目，无法确定的事项留待核。
3. **有变化才编辑。** 用宿主原生文件工具在同一份 `MEMORY.md` 中更新有关行。旧口径保留截止月，新口径标明起始月。需要会计决定时，先在当前会话确认具体口径和生效期。文件仅存简短规则和本机依据索引，原件、交易明细、身份及税务凭据信息留在原有位置。

本期取数仍按实际期间和来源处理。需要比较历史税负时，按需查[可比历史税负](references/materials-and-save.md#按需查历史税负)，有持续价值的已核结论可简记一行。具体历史案例和已选执行方法见[按需历史](../shared/references/business-memory.md)。实际凭证审批、入账和税务处理按各业务入口执行。

按[报告顺序](../shared/references/reporting.md)交代本期采用的口径、影响结果的变更和待核事项。
