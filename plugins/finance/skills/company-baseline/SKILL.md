# 账套记忆

1. **沿用当期口径。** 按绑定的账套和月份使用宿主已加载的账套 `MEMORY.md`。如需打开文件，用宿主原生文件工具读取 `.finance/business-session.json` 的 `memoryPath`。文件尚不存在时，从账套配置和代表性已过账历史中查本期需要的事实；必要时查同一业务的合同、凭证或申报依据。
2. **筛选已确认口径。** 每条都须有操作者确认或公司现行口径的可靠证据，换个月仍适用，且会改变做账决定。需要会计选择时先确认处理方式、生效期和适用范围。当期金额、单笔决定、暂定处理、未决事项及证据明细留在当期说明或底稿。
3. **按格式保存并读回。** 首次建立、口径变动或用户要求精简时，用宿主文件工具编辑绑定的 `MEMORY.md`。每条写一个可执行的选择，必要时标明适用条件和生效月。替换已有口径时写清旧口径截止月和新口径起始月。读回检查格式和三项条件，追溯确有需要时附一个短出处。

## MEMORY.md 格式

首次写入或统一旧版时采用下面结构。条目依据该账套的已确认口径填写，使用时按各自的适用月份核对。

```markdown
# 账套业务口径（精简）

- 企业：企业名称；账套 ID；本位币。
- 更新：YYYY-MM-DD。

## 已确认口径

1. 事项：具体处理方式（适用条件或生效期）。

本期判断和未决事项见当期说明。
```

本期取数按实际资料处理。需要比较历史税负时查[可比历史税负](references/materials-and-save.md#按需查历史税负)，具体历史案例和已选执行方法见[按需历史](../shared/references/business-memory.md)。实际凭证审批、入账和税务处理按各业务入口执行。

按[报告顺序](../shared/references/reporting.md)交代本期采用的口径、影响结果的变更和待核事项。
