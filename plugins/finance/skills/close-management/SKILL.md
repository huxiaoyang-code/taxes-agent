# 月结与年度核对指导

由 Anthropic 官方同名 Skill 改编，见 [来源](../../SOURCES.md)。保留日历和依赖作为可调整业务指导，不转化为运行时 DAG，不要求 Agent 先登记计划才能调用工具。

## 可调整的月结参考

| 参考阶段 | 常见工作 | 实际决定条件 |
|---|---|---|
| 月末前 | 收集合同、票据、流水、工资、库存及异常事项 | 真实截止日与资料到达情况 |
| T+1 | 核收付、计提、折旧摊销、采购销售完整性 | 原始支持及实际账簿是否可核 |
| T+2 | 核收入成本、应收应付、库存和关联交易 | 履约、批次、收付分配与比较明细 |
| T+3 | 试算、余额核对、调整草稿及差异调查 | 上游业务结果已足够支持 |
| T+4 | 税费底稿、报表草稿、重要差异解释 | 地区、税务资格、期间与原件支持 |
| T+5 | 实际复核、授权调整、结转及封账 | 工具检查、真实授权和未决影响 |

T+n只是上游日历的参考表达，不是法定期限、固定工期或强制五日流程。单人多企业可以按实际工作调整。独立且有资料的事项可先做，不能因一个项目缺件阻塞所有业务。

## 依赖判断

银行对账需要账簿与结单；往来核对需要业务和收付；报表计算需要有来源的期初与本期业务，未核部分须说明条件；税费核对需要适用资格、交易及期间资料。Agent据此选择工具和调查顺序，系统只记录实际调用与结果，不强制计划图或状态登记。

## 月结与年度工具

自主选择Python、表格公式或已有计算器，完成月结/年度计算与底稿；可选 `finance_workpaper`、`finance_tax_calculate`、`finance_annual_workpaper`。使用原生工具时按需读取支持期间和资料合同。真实账库查询、凭证写入、资产和期末操作保持正常业务控制。年度计算、年度关账、会计审定和申报提交是不同状态，不能因十二个月有结果就称年度完成。

## 复核与输出

交付 [财务报表](../financial-statements/SKILL.md)、[余额核对](../reconciliation/SKILL.md)、税费底稿及未决清单。每项说明已执行、待核、缺件或不支持，以及实际影响；实际复核者与日期不得代填。正式结账使用现有工具和真实授权，不绕过期间及完整性校验。

完整账期通过系统固定卡片交付，先看科目余额、银行和现金、税费及报表；凭证/计算、规则与采用参数按需查看，调用与原件保存在后台，见 [报告顺序](../shared/references/reporting.md)。模型不另写最终 HTML。
