# small-business 工作方法的账前适配

仅在核对关联、组织问询或判断范围时读取。本次借鉴工作方法，实际可执行字段和核对范围以 `finance_record_contract(recordType="prebook")` 及工具结果为准。来源与许可见 [SOURCES](../../../SOURCES.md)。

| 上游能力 | 保留的方法 | 本次中国账前适配 |
|---|---|---|
| `ap-processor` | 多源单据提取、去重、低可信字段留空、采购单与收货单核对、具体差异清单 | 商业账单与税务发票分开；对照采购、收货、发票、付款，不写应付账或支付 |
| `month-end-prep` | 相同期间与金额口径、重复及缺凭据检查、逐项解释、未解决事项随报告交付 | 以上期账和本期原始资料为依据，不要求本期已经记账或结账 |
| `cash-flow-snapshot` | 起始资金须有金额、日期和来源，已有收款不重复计入，缺余额不推断可用资金 | 核对本期实际资金与流水衔接，本期不输出 30／60／90 天经营预测 |
| `report-builder` | 指标写明公式、期间、来源和比较口径，同一输入可复算 | 系统生成固定账前报告；应纳税额和税负率分列，未核条件随金额展示 |
| `inventory-planner` | 商品标识、库存日期和单位、在途/已到货区分，资料缺口按商品报告 | 核对本期采购收货与结存；销量预测、缺货日和采购建议留待后续 |

## 判断关联和差异

1. **证据种类不同。** 供应商对账单用于发现缺口，不凭一行汇总就冒充完整发票；银行卡消费不等于待付账单；税局发票不独立证明收货、付款或用途。
2. **相同单据不重复计数。** 同一张票在税局导出、老板附件和供应商对账单中出现，保留各自来源及关联。关键值不一致时留冲突，不能选一个好看的值或静默覆盖。相同供应商的相同金额可能是不同交易。
3. **先有业务关联，再比较金额和数量。** 支持证据中的采购号、收货号、发票号和付款关联；只有金额相同只算候选线索。一个付款覆盖多笔业务、部分收货或部分开票，需要保留分配依据；合同不能表达的情形明确列人工核对，不伪造一一对应。
4. **时点差异不直接判错。** 已收货待开票、有票未付款、结清上期欠款和本期预付款是不同情形。应向老板核实未明部分，而非把所有未匹配项都归为漏票或漏账。
5. **不照搬上游阈值。** 上游美元金额、日期窗口和采购容差属于示例。中国税率、优惠、抵扣条件和业务重要性须使用本期实际依据；工具发现的具体差异不可被文本容差自动抹除。

## 问询与报告

每项尽量回答：哪笔业务、已有什么证据、差多少、现在不能确定什么、需要哪项说明或材料、影响哪项核对或测算。缺证据导致的金额影响不确定就写未知，不给伪精确税额。

老板解释、已补材料、再次核对结论分开。清单可以按缺件、金额/数量冲突、业务用途待解释分组；结清上期、代收代付等分类须有依据。未解决事项继续随交接包传递，不以“老板已回复”作为全部消除条件。

本期税务能力由中国后端承担。上游 `tax-season-organizer` 的美国联邦税、1099、W-9 路径和示例公式未迁入；纳税人身份、交易范围、法定期间及资格须来自本期资料或明确声明。
